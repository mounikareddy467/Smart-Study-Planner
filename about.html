About

A modern web application for efficient study planning and task management.

Project Overview

Smart Study Planner is a responsive web application designed to help students organize their study schedule, manage academic tasks, and monitor their learning progress through an intuitive and user-friendly interface.

The application enables users to create, update, delete, search, filter, and categorize study tasks while automatically saving all data using the browser's Local Storage. It also provides progress tracking, task analytics, and a calendar view for better time management without requiring user authentication or a backend server.

Technology Stack

  • HTML5
  • CSS3
  • JavaScript (ES6 DOM Manipulation)
  • Bootstrap 5
  • Browser Local Storage

Key Features

Create, Update and Delete Tasks
